Charity Website

Project Description

This is a simple charity website created using Python and Flask and deployed on Google Cloud App Engine.

Features

•⁠  ⁠Simple charity homepage
•⁠  ⁠Form for visitors to enter their names
•⁠  ⁠Thank-you message after submitting the form
•⁠  ⁠Automatic scaling using Google App Engine

Technologies Used

•⁠  ⁠Python
•⁠  ⁠Flask
•⁠  ⁠Google Cloud App Engine
•⁠  ⁠GitHub

Deployment

The website was deployed using Google Cloud Shell with the command:

gcloud app deploy

Automatic Scaling

The application uses the F1 instance class with a maximum of 2 instances.

Cloud Service Comparison

Service	What You Manage
App Engine	Application code and configuration
Cloud Run	Container and application configuration
Virtual Machine	Operating system, server, and application

Conclusion

Google App Engine makes deploying websites easier because developers do not need to manage servers.sa
